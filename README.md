# Contador

## Sobre o projeto

Este projeto foi desenvolvido para a disciplina de Programação de Aplicativos Mobile (PAM). O aplicativo consiste em um contador, permitindo praticar os conceitos de programação e desenvolvimento de aplicativos mobile.

## Tecnologias utilizadas

- Flutter
- Dart
- Visual Studio Code (VS Code)

## Objetivo

O objetivo do projeto é desenvolver um aplicativo simples utilizando Flutter e Dart, colocando em prática os conhecimentos adquiridos durante as aulas de PAM.
